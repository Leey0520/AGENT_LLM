# 日常分析流程模板

## 目标

说明固定分析要支持的业务决策、频率、负责人和交付对象。

## 输入

列出使用的正式指标、事件、属性、时间范围、分群和版本范围稳定 ID。

## 步骤

1. 检查数据到齐时间和已知问题。
2. 运行经过审批的查询或分析资产。
3. 校验总量、分母、异常峰谷和版本变化。
4. 区分事实、解释假设和待验证项。
5. 按指定飞书文档或看板格式交付。

## 异常门槛

填写触发复核的绝对变化、相对变化、最小样本和连续天数，不使用没有业务依据的统一阈值。
