# 战魂铭人彼岸试炼渗透率与难度分层口径

## 业务问题

本页定义一个模式的渗透率：在指定观察窗口内，各最高通关难度分层的活跃设备中，有多少设备进入「彼岸试炼」。它描述参与覆盖，不证明模式对留存或付费产生了因果影响。

本页不定义固定日期窗口。本次已确认的分析实例为 2026-07-28 至 2026-08-28，含首尾。

## 指标口径

| 项 | 定义 |
| --- | --- |
| 指标 | 彼岸试炼渗透率 |
| 分子 | 当日 `enter_level` 且 `mode_name = '彼岸试炼'` 的去重设备数 |
| 分母 | 当日 `tap_start` 的去重设备数 |
| 主体 | 客户端 `#device_id` |
| 事件族 | 只使用单人 `enter_level`、`game_over`；不使用 `remote_enter_level` 或局域网、远联事件族 |
| 时间 | 客户端事件按北京时间自然日；项目时区为 `Asia/Shanghai` |
| 粒度 | 日期 × 最高通过难度分层 |
| 作弊过滤 | 当前实例不排除作弊设备；若后续变更必须重述口径 |
| 零事件 | 当日无分子时记为 0；分母为 0 时比率不可计算 |

## 难度分层

| 项 | 定义 |
| --- | --- |
| 分层主体 | 每个 `#device_id` 一个静态标签 |
| 分层范围 | 可见全历史至分析截止日；本次实例截至 2026-08-28 |
| 有效模式 | `空间碎片-终章`、`空间碎片-天人`、`空间碎片-狱`、`空间碎片-兽`、`空间碎片-人`、`空间碎片-诡`、`空间碎片-修罗` |
| 通关判定 | `game_over` 且 `reward_calculate IN ('success','success_special')` |
| 难度值 | 对有效通关记录取最高 `#vp@num_difficult_level` |
| 未通关 | 截止日没有任何有效通关记录的设备，单独归为「未通关」，计入活跃分母 |
| 动态性 | 静态回看标签，不是「当日为止」动态标签 |

静态回看会把截止日才首次通关高难度的设备追认到较早日期。若业务需要当日动态难度，必须另建按日重算口径，不能复用本页结果。

## 计算

对每个日期和分层：

`渗透率 = 当日该分层进入彼岸试炼的去重设备数 ÷ 当日该分层活跃去重设备数`

按全部设备汇总时，先分别汇总分子和分母再相除；不能对每日渗透率做简单平均。

## 验证

- 各分层活跃设备数按日求和后，应与当日整体活跃设备数一致。
- 各分层彼岸试炼设备数按日求和后，不应超过当日进入该模式的整体去重设备数。
- 与现有彼岸试炼看板比较整体趋势和量级；差异必须从模式枚举、事件族、分母事件或静态分层时点中定位。
- 检查 `#vp@num_difficult_level` 的类型、空值和值域；字段不可用时停止执行并按已确认口径修订。
